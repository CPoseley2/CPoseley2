# Collin “Keek” Poseley

**Software engineer & educator · Apple platforms · Learning technology · Creative tools**

I build intuitive software that helps people learn, create, and work together. My work connects native Apple development, spatial computing, and practical tools for creative and community workflows.

## About me

I’m an educator turned engineer with a master’s degree in Educational Technology. My background spans more than a decade of work across learning experiences, technology, and technical mentorship, including designing XR learning experiences and mentoring technical teams at Apple.

My engineering experience includes visionOS triage automation, Apple Pay integration on iOS, and internal tools that improve developer workflows and system stability. I bring an educator’s perspective to engineering: understand the person using the tool, make complex ideas approachable, and give people clear feedback as they work.

That perspective also shapes my independent projects. Whether I’m building a control surface for a Mac, organizing visual references for a production, or simplifying a soccer club’s season planning, I’m interested in software that makes a real task easier to understand and complete.

## Selected projects

### [Tenki](https://cposeley2.github.io/tenki-support/)
**An iPhone and iPad control surface for macOS.**

Tenki connects mobile interaction with desktop workflows. Its public product site brings together companion downloads, support, accessibility information, and privacy documentation.

[Product & support](https://cposeley2.github.io/tenki-support/) · [Public support repository](https://github.com/CPoseley2/tenki-support)

### [Reference Desk](https://github.com/CPoseley2/reference-desk)
**A local workspace for the visual decisions behind a production.**

A tool for filmmakers, animators, and independent storytellers to organize characters, costumes, locations, and props; compare image versions; and record explicit approvals. Built with a Python backend and browser interface, with local project libraries and optional AI image generation.

[Source & documentation](https://github.com/CPoseley2/reference-desk) · [Project overview](https://cposeley2.github.io/reference-desk/)

### [Fair Oaks Soccer Club Team Hub](https://github.com/CPoseley2/Brahma)
**A community operations prototype for coaches, coordinators, and families.**

A web application for season planning, schedules, equipment, budgets, and family communication. Built with JavaScript, an MVVM architecture, Firebase Authentication, and Cloud Firestore. The board demonstration uses synthetic data to make planning scenarios easier to evaluate.

[Source & documentation](https://github.com/CPoseley2/Brahma) · [Board walkthrough](https://fair-oaks-u6-team-hub.web.app/board-readme.html)

## How I approach the work

- **Start with the person and the task.** Use real workflows to guide product and interface decisions.
- **Make complexity understandable.** Favor clear navigation, useful feedback, and documentation that helps people move forward.
- **Build for continued use.** Treat maintainability, accessibility, privacy, and reliable behavior as part of the product.
- **Connect disciplines.** Bring lessons from education, engineering, and storytelling into the same design process.

## Beyond the code

Storytelling is a recurring thread in my work, from immersive learning to historically grounded creative projects. I’m interested in how language models and other creative tools can support research, iteration, and expression while keeping human judgment central.
